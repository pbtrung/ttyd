# JetBrains Mono

JetBrains Mono 2.304, the latest official release as checked on 2026-11-04:
https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304

Regular, Bold, Italic and Bold Italic WOFF2 files are bundled locally under the
SIL Open Font License (see `OFL.txt`). No font CDN requests are made.

Run `yarn build:fonts` from `html/` to restore these files from the official release.
